# TO RESUME LONG RUNNING TASKS
For long-running tasks, maintain TASK_STATE.md.

Keep it updated with:
- original objective
- completed work
- remaining work
- important architectural decisions
- modified files
- tests already performed
- known issues
- next action

If the conversation context appears incomplete or a task is resumed
after an interruption, first inspect TASK_STATE.md, git status,
git diff and the repository before continuing.
Do not repeat completed work.
